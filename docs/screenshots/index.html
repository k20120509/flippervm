01 · 启动界面(未加载固件)

左侧橙色 FlipperZero 外观面板 + LCD 屏幕区 + 方向/OK/Back 按键。右侧是加载固件/运行/暂停/单步/复位按钮、速度滑块、寄存器状态、UART 控制台。

02 · 加载演示固件 · LCD 显示成功

屏幕点亮,ST7567 128x64 SPI LCD 成功显示:FLIPPERVM OK! / DEMO FIRMWARE RUN / LCD 128x64 SPI / UART TX:ON CPU:RUN / KEYPAD:WORKING v0.3.0。

03 · 按键面板 + UART 控制台(启动日志)

PC=0x08000008 · SP=0x20008000 · icount=120000。SysTick / GPIO keys / SPI2 LCD 均初始化成功,CPU 进入 idle 循环,等待按键输入。

04 · OK 键按下 → iAPP 主菜单

屏幕显示 IAPPS MENU,UART 输出 8 项 iAPP:1.Sub-GHz 2.1-Wire 3.NFC 4.Infrared 5.GPIO 6.iButton 7.Bad USB 8.U2F。

05 · 运行 Sub-GHz iAPP

屏幕标题 SUB-GHZ: LISTEN。UART 输出:Radio: CC1101 init @ 433.92MHz OK / Listening... (timeout 30s)。

06 · 暂停 · 单步调试模式

屏幕显示 PAUSED (STEP MODE),可点「单步(1000)」一步步追踪 iAPP 代码。
